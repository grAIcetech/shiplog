# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-05-26

### Added

- Single-file HTML dashboard with dark-mode UI
- Status filtering (Done, Open, Blocked, Waiting, In Progress)
- Dynamic category filter buttons generated from data
- Full-text search across requests, categories, artifacts, and notes
- Editable notes with localStorage persistence
- One-click Markdown export
- Progress bar with completion percentage
- Stats cards for at-a-glance status counts
- Responsive layout with horizontal scroll on mobile
- 5 demo entries to illustrate the data format
- Inline comments showing where to customize data, categories, and branding
